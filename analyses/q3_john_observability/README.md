# Question 3: Exoplanet Observability

**Owner:** John Frasier

## Specific Question

Which possible exoplanets are easiest to observe with telescopes based on distance, host-star brightness, and transit signal depth?

## Planned Analysis

This analysis will examine:

- Distance from Earth
- Host-star brightness
- Transit signal depth
- Gaia parallax
- Gaia brightness measurements

NASA and Gaia DR3 data will be connected using the host star’s Gaia identifier.

This folder will eventually contain John’s code, notes, tables, figures, and conclusions.
